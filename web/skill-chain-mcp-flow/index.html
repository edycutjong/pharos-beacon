      What's ours

      Beyond the requirement list

      Rules you can check

      The verdict names the rule that decided it, in words: confirmations against the value tier (3, 12 or 32), the receipt status, or the missing transaction.

      Five answers, not two

      WAIT says how many blocks and about how many seconds are left, from the observed block time; MISMATCH checks the expected recipient and minimum value.

      Installable as a skill

      The same SKILL.md frontmatter as PharosNetwork's pharos-skill-engine skills, installable with npx skills add.

      How this was built
      Built with Claude as a coding assistant. The design, the failure cases and the extra feature were chosen by me; the commit history shows the iterations.
