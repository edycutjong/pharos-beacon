Audit-Log Agent

Reads one wallet's activity from the chain, groups it into transfers in and out, swaps, approvals and contract calls, totals each category and lists the notable transactions with explorer links. It reports how many of the wallet's sent transactions it found against the chain's own count.

      What's ours

      Beyond the requirement list

      Checked against the nonce

      The chain's transaction count for the wallet says how many it sent; the report says how many it found, and searches for the rest.

      Unlimited approvals stand out

      An approval to spend without limit is listed as notable, one per spender.

      Honest coverage

      Incoming native transfers leave no log, so the report says they are invisible rather than implying a complete history.
