x402 Paywalled API

An API that charges per request in test USDC on Pharos Atlantic. It answers 402, takes a signed payment, settles it through its own facilitator and returns the data with the receipt.

      03

      What's ours

      Beyond the requirement list

      Receipt check

      The buyer does not trust the PAYMENT-RESPONSE header alone. It reads the settle transaction's receipt on Atlantic and only accepts the data when the receipt says status 1 and a USDC Transfer from the payer to the payee matches the price.

      Replay refused

      The same signed payment sent twice gets a second 402. Before verifying or settling, our facilitator reads the EIP-3009 nonce on chain (authorizationState); a used nonce is refused. Press “Replay a payment” to see it live.

      Price on the 402

      Every 402 states the price, the asset and the payee in plain words, so an agent (or a person) can decide before signing anything. Open the paid route without paying to read it.

      How this was built
      Built with Claude as a coding assistant. The route design, the prices, the failure cases and the receipt check were chosen by me; the commit history shows the iterations.
