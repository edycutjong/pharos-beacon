x402 Agent Buyer

An agent that buys from x402-paywalled APIs inside a budget and a per-call price cap. This page shows its decision plan: it asks the paywalled API for each price (an unpaid request, answered 402) and applies the agent's own rules. The paying run, with signing, safe retries and the payment log, is the CLI's.

      What's ours

      Beyond the requirement list

      Value check

      Before paying for a whale question the agent compares the range of an answer it already bought; a covering answer saves the price. The page marks those rows “check first”.

      Idempotent payments

      One idempotency key per purchase and a journal written before the send mean a crash or a lost response never pays twice.

      A plan before the spend

      Prices are read from the 402 first, so the cap and the budget refuse before anything is signed.

      How this was built
      Built with Claude as a coding assistant. The design, the failure cases and the extra feature were chosen by me; the commit history shows the iterations.
