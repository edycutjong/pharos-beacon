Beacon demos

Twenty-four Pharos Agent Arena tasks. Twenty-one of them run from this site: press Run live and the page calls the real chain, Pacific mainnet or Atlantic testnet, and links every result to the explorer. Nothing here asks for a wallet. Steps that sign are shown from the recorded runs committed in the repo.
