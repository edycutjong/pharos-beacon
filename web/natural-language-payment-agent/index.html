Natural-Language Payment Agent

Turns “send 0.0001 PHRS to 0x…” into an unsigned transaction and a wallet signing request. It asks a follow-up when something is ambiguous, validates the recipient, the token and the balance, and shows a plain-words summary first. It never signs or sends.

      Beyond the requirement list

      Asks, never guesses

      A missing token or recipient becomes a question, and the answer is a follow-up turn.

      Two languages

      English and Bahasa Indonesia instructions are parsed by the same rules.

      Reference on chain

      The CLI can carry a reference in the transaction data; the checks name its size limit.
