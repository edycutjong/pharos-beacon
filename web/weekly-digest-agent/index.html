Weekly Digest Agent

Builds a digest of a wallet's activity for a period and compares it with the period before: key numbers, the top three notable events, who is new. On a schedule the CLI posts it to Discord; this page builds the same digest for the last blocks and sends nothing.

      What's ours

      Beyond the requirement list

      Once per period

      A state file makes a daily trigger safe: a period already delivered says so and exits.

      Fail closed

      No digest without the previous period's numbers, so the comparison is never silently missing.

      Ranked, not listed

      Notable events are scored: unlimited approvals and failures first, then the biggest moves by their share of the period.
