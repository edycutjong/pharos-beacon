Invoice-to-Payment Agent

Reads an invoice, in JSON or as plain text, in English or Bahasa Indonesia, pulls out payee, amount, token and reference, and flags what is missing or inconsistent instead of guessing. A clean invoice becomes a payment summary and an unsigned transaction that carries the invoice reference.

      What's ours

      Beyond the requirement list

      Flag, don't guess

      A USD invoice is not paid in USDC unless the caller says so, and then the 1:1 assumption is printed.

      Fingerprint

      Number, issuer, amount and currency make one fingerprint; the CLI's ledger refuses to pay the same one twice.

      Three layouts

      Labelled lines, JSON keys and Indonesian labels (Total tagihan, Bayar ke) are all read by rules.

      How this was built
      Built with Claude as a coding assistant. The design, the failure cases and the extra feature were chosen by me; the commit history shows the iterations.
