Wallet Risk Checker

A check to run before you send to an address. It reads the address's history on Pharos, scores six signals and answers low, medium or high, with every red flag explained in plain words.

Reads only. Mainnet through the hosted Chain MCP; Atlantic through its public RPC, because the Atlantic Chain MCP runs locally and cannot run here. The CLI reads 30,000 blocks of token history; this page reads 5,000 at most.

      Beyond the requirement list

      A gate in front of the send

      gate --to … --amount … checks the recipient first. At HIGH it refuses, writes the refusal to the Policy Gatekeeper's hash-chained audit log as rule wallet_risk and never asks the policy or sends. Otherwise the Policy Gatekeeper decides as usual. Both outcomes are recorded in section 02.

      High without any list

      An unlimited allowance to an address with no code is the approval-phishing pattern, so it is HIGH on its own. Press “Risky wallet, flagged list emptied”: the staged wallet stays HIGH with our list empty.

      Honest about its list

      The flagged list is our own file with one made-up entry, and the page says so. The risky wallet was created and staged by us on Atlantic; its four setup transactions are linked below.

      How this was built
      Built with Claude as a coding assistant. The design, the failure cases and the extra feature were chosen by me; the commit history shows the iterations.
