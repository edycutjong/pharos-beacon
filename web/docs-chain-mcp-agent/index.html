Docs + Chain MCP Agent

Explains a contract function from the Pharos Developer Docs MCP, with the pages it cites, then calls the same function on Pharos mainnet through the Chain MCP and reads the result against that explanation. When the docs do not describe a function, it says so.

      What's ours

      Beyond the requirement list

      Grounding check

      askQuestion is a language model and can answer from general knowledge. Its answer only counts when a page it cites, fetched with getPage, names the function (exact, case-sensitive). Otherwise the agent prints NOT DESCRIBED and gives no explanation and no unit. Try “WPROS · totalSupply()”.

      Units from the chain

      The unit is never taken from the docs prose: balanceOf and totalSupply are divided by the contract's own decimals() at the same block, and only for a function the docs explained.

      One block, no model of ours

      Every read is pinned to one block from get_block_number, and the reading is deterministic code: the same docs answer and chain state give the same report. The contract address is also checked against the docs Token Registry page.

      How this was built
      Built with Claude as a coding assistant. The design, the failure cases and the extra feature were chosen by me; the commit history shows the iterations.
