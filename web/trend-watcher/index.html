Trend Watcher

A skill with memory. Each run stores one observation of a chain metric and acts only when the stored history shows N moves in a row in one direction, never on a single spike.

A replay re-reads every stored observation at its own block and checks it against the committed history file. Reads only; mainnet via the hosted Chain MCP, Atlantic via its public RPC.

      What's ours

      Beyond the requirement list

      Sparkline and slope

      The history draws a sparkline of the stored values, and the alert carries the slope of the streak per observation and per block (the “alert” line under each live result is built by the same function that sent the Discord message).

      A spike ten times deeper

      A second Atlantic history makes the lone dip 10× larger than each trend step. Replay it: the deep dip reverses and does nothing; three small falls in a row fire.

      Kill -9 safe

      The history file is written atomically under a lock and de-duplicated by block, so a crash cannot lose or repeat an observation; a test kills a writing process with kill -9 in a loop. The alert is marked sent only after it was sent.

      Built with Claude as a coding assistant. The design, the failure cases and the extra feature were chosen by me; the commit history shows the iterations.
